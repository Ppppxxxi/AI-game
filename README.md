# 江湖有信 · 渡口无归人

一款可玩的江湖叙事原型。七日渡口、五个人、三结局。话可以随便说，事实由引擎裁定。嘴里说完成了，不算。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`（或终端里给出的端口）。

## 这一局在做什么

- 第一日茶肆已经有事：冷茶、闩着的门、昨夜来找说书人的姑娘。
- 和人说话用白话。能说的说完，不能说的告诉你原因。
- 作保、传话、承诺、夜茶，先落成确认。双方都做到才算数。
- 手记记下听见的和看见的。两条对得上，才写在一起。
- 你说出去的话，夜里会自己走路。

## 边界

模型只替人说话。记忆、履约、结局和谁知道什么，都在引擎里。
